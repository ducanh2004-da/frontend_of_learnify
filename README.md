# learnify-fe-tanstack

Learnify is an educational platform that highlights the future and craft of learning—from foundational concepts to hands-on practice to career-ready mastery. Built with React 19, TanStack Start (SSR), TypeScript, and GraphQL.

---

## Documentation & Guides

- 📘 **[Project Architecture, Technology Stack & Vercel Deployment Guide](./PROJECT_GUIDE.md)**: Full breakdown of project structure, technology choices, routing, state management, and step-by-step instructions to deploy the application on **Vercel**.
- 🛠 **[Frontend Integration Guide](./frontend-integration-guide.md)**: GraphQL API contract, enums, mutations, queries, and authentication flows with the backend.
- 📋 **[AI Agent Rules & Guardrails](./antigravity-rules.md)**: Coding conventions and constraints for frontend engineers and AI assistants.

## Quick Start

```bash
# Install dependencies
pnpm install

# Generate GraphQL types
pnpm codegen

# Start development server
pnpm dev
```
